# Burner Growth Audit

**Live → https://eddieatadapty.github.io/burner-flow-rebuild/**

Five ideas to turn more Burner users into subscribers, each built into a clickable version of Burner's own onboarding. Prepared by Adapty.

| # | Idea | Potential outcome |
| :-- | :-- | :-- |
| 01 | Let them pick their number before the paywall | +10–20% CR to purchase |
| 02 | Ask what the number is for, then use the answer | +10–15% CR to purchase |
| 03 | Put your proof where they decide | +5–15% CR to purchase |
| 04 | Make the annual plan the easy pick | +10–15% ARPU (more annual plans) |
| 05 | Catch the people who close the paywall | +5–10% ARPU |

Every price, rating and feature comes from Burner's App Store listing, website or in-app screens. Impact ranges are Adapty’s expected effect from teardowns and A/B tests across 30,000+ subscription apps, not measured lift for Burner. They overlap, so they don’t add up.

Static single page, no build step: `python3 -m http.server`.
